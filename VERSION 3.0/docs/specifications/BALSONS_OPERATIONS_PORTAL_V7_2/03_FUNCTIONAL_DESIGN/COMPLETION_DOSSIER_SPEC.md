# MECHANICAL COMPLETION DOSSIER SPECIFICATION
**Governing Standard:** BAL-OPS-E2E-007 V7.2 (§07 & §14)  

### 1. Scope of Mechanical Completion
Mechanical completion represents the formal exit from BALSONS installation scope. It verifies that:
1. Equipment is completely unboxed, cleaned, and placed on foundation pockets.
2. Base plates and mounting bolts are installed.
3. Rough levelling is verified to within contractual tolerance (&plusmn;1.0 mm).
4. X-Y axis centerlines are aligned with bay benchmarks.

### 2. Mandatory Dossier Contents
- Scope verification checklist signed by Area In-Charge.
- Spirit / laser levelling inspection measurement log.
- Centerline / coordinate alignment verification sheet.
- Punch point register (categorized into Category A Blocker vs Category B Minor).
- Photographic completion record.
- Client / OEM representative counter-signature.
