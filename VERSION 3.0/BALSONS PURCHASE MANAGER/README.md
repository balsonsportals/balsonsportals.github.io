# BALSONS Purchase Manager
## Commercial Procurement, RFQ Floating & Vendor Comparison Portal

**Anchor Project:** Jupiter Tatravagonka Railwheel Factory (JTRWF), Khordha, Odisha  
**Architecture Standard:** `BALSONS-SAM-2026` / `BEDS V1.0`  
**Governance Policy:** `Global Super Administrator Policy (Version 1.0)`  

### Module Scope & Capabilities:
- Material and tackle procurement requests originating from Store Manager
- RFQ (Request for Quotation) generation and vendor commercial comparisons
- Purchase Order (PO) processing and approval workflows
- Inward material delivery and gate entry clearance tracking
- Inter-synchronized with Store Inventory, Gate Entry, and Central Accounting
